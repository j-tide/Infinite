## 实施、核验和修正

7. AI 并行分工编写领域模型、节点界面、图片资源和浏览器测试；部分并行回合遇到连接错误，没有产生文件。随后缩小分工，主会话接续 store 和节点组件，其他工作分别完成资源、领域 helper、测试和 README。连接错误不计作功能验收。
8. 自创四张本地 SVG，XML 校验通过。领域测试先覆盖引用校验、世界坐标、序列化剥离临时 UI 状态、刷新中断和损坏数据保护。
9. mock 任务提交时快照图片资产、提示词和比例；排队和运行使用异步定时器。失败开关只影响下一次提交；重试复用原快照，新建任务。生成节点被删除时中断其任务，延迟回调检查任务状态，避免出现孤立结果。
10. 浏览器验收使用真实按钮、输入、拖动和端口连接；读取 localStorage 用于断言。缺输入时按钮禁用且显示操作说明，测试核对此行为，不尝试点击被禁用按钮。
11. Playwright 自带 Chromium 下载超时，改用本机已安装 Chrome；配置仍支持标准 Chromium 安装和环境变量指定浏览器。npm 初始 Vitest 3 存在开发依赖漏洞，确认 Node/Vite 兼容性后升级为 Vitest 4.1.11；最终安装输出为 0 vulnerabilities。

## 最终验收证据

2026-10-01 实际完成以下检查：

- `npm test`：26/26，通过领域 10 项和 store 16 项。
- `npm run test:e2e`：8/8 通过，33.5 秒；使用本机 Chrome，真实鼠标、键盘、输入、端口拖动及刷新。
- `npm run build`：TypeScript 和生产构建通过。
- `openspec validate build-p0-canvas-demo --strict`：通过。
- `npm ci --dry-run`：锁文件安装检查通过。升级 Vitest 后安装审计输出为 0 vulnerabilities。

首轮浏览器验收发现生成节点重复添加仅偏移少量坐标，会使节点重叠而无法连接结果。主会话修改为基于世界坐标和节点尺寸寻找空位，多次结果纵向分开放置，再以原真实连线断言复验。精确拖动测试还发现默认拖动阈值会消费首次移动，主会话将标题拖动阈值设为 0，保留完整位移与比例换算断言。

两项测试方式得到修正：等待保存完成后再读取最终坐标，避免断言拖动中间状态；损坏数据在下一页面初始化前注入，避免旧页面 pagehide 保存将其覆盖。没有删除或放宽结果复用、坐标换算或数据保护的验收要求。
