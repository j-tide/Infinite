# Proposal

## Why

当前目录只有面试题和 OpenSpec 配置，需要一个能现场创建、连接、生成并刷新恢复的 AI 图片创作画布 demo。先完成题目 P0 的完整闭环，为交互、引用关系、异步任务和持久化提供可验证的实现。

## What Changes

- 新建单项目前端应用，界面创建图片、提示词和生成节点，支持世界坐标下的拖动、平移、鼠标锚定缩放和删除。
- 连接图片及提示词输入，使用内置示例图片执行有真实延迟的 mock，提供可控失败、参数保留、重试和重复提交防护。
- 每次成功产生独立任务、图片资产和结果节点；结果节点可继续作为生成输入。
- 持久化带版本的画布、视口、连接、资产与任务；刷新后未完成任务标记为已中断，可重试。
- 提交运行说明、验收步骤、已知限制、AI 使用记录及后端追问准备。
- 本轮仅 P0，使用内置资源；P1、上传、真实生成服务、完整后端及多项目管理留在后续范围。

## Capabilities

### New Capabilities

- `canvas-editing`: 三类节点的创建、编辑、选择、移动、删除、视口操作以及类型明确的有向连接。
- `generation-tasks`: 可追踪的异步 mock 任务、可控失败和重试、独立结果资产及结果节点流转。
- `canvas-persistence`: 版本化单项目本地保存、资源引用恢复、任务终态与中断恢复策略。

### Modified Capabilities

无现有能力需要修改。

## Impact

新增 React / TypeScript / Vite 前端，使用 React Flow 承担画布坐标和连线交互，Zustand 管理领域状态。存储使用 localStorage，无外部 API、账号或密钥。新增本地 SVG 示例资源、领域单元测试及浏览器验收测试；提供依赖锁文件和 README。
